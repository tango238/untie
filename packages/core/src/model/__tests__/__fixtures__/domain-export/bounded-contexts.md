## Bounded Context 一覧

### 受注 (Core)
- **英語名**: Ordering
- **責務**: 注文を受け付けてから出荷を頼むまでと、返品を受け持つ。
- **主要概念**: Order (集約), ReturnRequest (集約)
- **ユビキタス言語**: 注文
- **所有チーム**: EC 運営
- **実装するシステム**: 販売管理システム
- **分析のコンテキスト (Untie)**: 注文

### 在庫 (Supporting)
- **英語名**: Inventory
- **責務**: 売れる数を正しく保つ (入荷・引き当て・棚卸)。
- **主要概念**: Stock (集約)
- **ユビキタス言語**: 在庫、引き当て
- **所有チーム**: 倉庫
- **実装するシステム**: 販売管理システム
- **分析のコンテキスト (Untie)**: 商品・在庫

### 出荷 (Supporting)
- **英語名**: Shipping
- **責務**: 送り状を発行し、荷物を出す。
- **主要概念**: Shipment (集約)
- **ユビキタス言語**: TBD
- **所有チーム**: 倉庫
- **実装するシステム**: 販売管理システム
- **分析のコンテキスト (Untie)**: 出荷

### 決済 (Generic)
- **英語名**: Payment
- **責務**: 外部の決済サービス。入金の結果だけを受け取る。
- **主要概念**: なし (外部のコンテキスト)
- **ユビキタス言語**: TBD
- **所有チーム**: TBD
- **実装するシステム**: 決済サービス

### 会計 (Generic)
- **英語名**: Accounting
- **責務**: 売掛金と入金を管理し、月次の数字を出す。
- **主要概念**: Receivable (集約), Payout (集約)
- **ユビキタス言語**: TBD
- **所有チーム**: 経理
- **実装するシステム**: 会計システム
- **分析のコンテキスト (Untie)**: 会計

## 言語の境界で発見した事実
- 「出荷」(出荷) の語が、別のコンテキストの「出荷済」(注文)にも出ています
- 「入金」(会計) の語が、別のコンテキストの「入金済」(注文)「入金が確認された」(注文)にも出ています
